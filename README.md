# 📊 Instagram User Analytics

### 🎯 Project Objective
The goal of this project is to analyze **user interaction and engagement** on Instagram using SQL.  
It focuses on understanding user behavior, identifying trends, and detecting suspicious accounts (bots).

---

### 🧩 Approach

1. **Database Creation:**  
   Created a new database named `ig_clone` in MySQL Workbench.

2. **Data Cleaning:**  
   Checked for nulls, duplicates, and ensured consistency.

3. **SQL Analysis:**  
   Solved key business questions on user engagement, marketing strategy, and investor insights.

---

### 🧠 Key Insights

- **26 users** have never posted any photo.  
- **Winner of contest:** `Zack_Kemmer93` (User ID: 52, Likes: 48)  
- **Top hashtags:** `#smile`, `#beach`, `#party`, `#fun`, `#concert`  
- **User registrations peak:** Thursday and Sunday.  
- **Average posts per user:** 2.57  
- **13 potential bot accounts** detected liking all photos.

---

### 💡 Recommendations

- Schedule ad campaigns on **Thursday evenings and Sundays** for maximum engagement.  
- Use hashtags like `#fun`, `#beach`, `#concert` for better reach.  
- Implement bot detection to maintain organic engagement.
